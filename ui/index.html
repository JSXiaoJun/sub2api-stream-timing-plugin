计时从发起上游请求开始，包含连接与上传。响应头、心跳、空的准备事件仍算等待；首个有效模型输出在期限内到达，就保持原事件传输。

释放的是提示／首次处理名额；HTTP 连接、正文转发与错误检测继续运行。随机范围限定插件等待阈值，使用记录还可能包含插件之前的处理耗时。

空提示发出后，宿主输出前自动换号的机会结束。本插件可在首次上游事件透传之前，对明确 503／过载使用同一账号和请求体作有限重试；不是换号。0.1.4 同时识别错误码为空、错误文字为 “Our servers are currently overloaded. Please try again later.” 的失败。响应标识、心跳、正文或工具事件一旦透传，就不再重放。次数／时间耗尽后仍返回真实失败，不伪造成功。支持 OpenAI OAuth HTTP Responses 与 API Key 流式 HTTP Responses；API Key 非流式、原生 Chat Completions、其他端点及原生 WebSocket 保持宿主路径。同一传输能力的过载冷却插件需先停用。
